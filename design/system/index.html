ptreport design system, Night Shift

Every component of the app in every state, split into groups. Built from tokens.css and components.css only.

  1. Foundations3 components

    Palette, type scale and the icon set every other group is built from.

  2. Actions6 components

    Buttons in four roles and two sizes, icon-only buttons, links.

  3. Form7 components

    Text fields, CWE combobox, selects, prose and mono text areas, target checkboxes, file input.

  4. CVSS5 components

    Version switch, metric option groups and the vector strip, the direction's signature move.

  5. Navigation4 components

    App shell bar, breadcrumb, tabs and the export menu.

  6. Overlays3 components

    Confirm dialog and toasts.

  7. Content8 components

    Findings table, severity badges, status labels, target chips, summary bar, empty state.

  8. Evidence and code2 components

    HTTP request and response pair, code block.

  9. Feedback2 components

    Inline messages, loading and progress states.

  10. Report document (light palette)1 component

    The light palette of the exported report: heading, facts, code.

Hanken Grotesk and JetBrains Mono, self-hosted, SIL OFL 1.1
