CWECWE-89 Improper Neutralization of Special Elements used in an SQL Command ('SQL Injection')
CelPublic API

Opis

Parametr id jest bezpośrednio konkatenowany z zapytaniem SQL.

Wpływ

Atakujący bez uwierzytelnienia może odczytać i zmodyfikować całą bazę danych.

Dowód koncepcji

sqlmap -u 'https://api.acme.example/v2/orders?id=1' --batch --dbs

Zalecenie

Stosować zapytania parametryzowane (prepared statements).
